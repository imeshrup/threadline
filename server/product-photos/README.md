# Product photos

Put real product photos here, then run `npm run seed` again (note: seeding resets products, orders and users).

Name each file `<product-slug>-<number>.<jpg|jpeg|png|webp>`. Photo 1 is shown for the product's first color,
photo 2 for the second color, and so on. Products without photos keep their generated illustration.

Example: `everyday-organic-tee-1.jpg` (White), `everyday-organic-tee-2.jpg` (Black)

Tips: use the same aspect ratio for every photo (portrait 4:5, e.g. 1200x1500), a plain white or light grey
background, and only photos you own or that have a licence allowing commercial use (your own shoots,
your suppliers' official images with permission, or free-licence sites like Unsplash/Pexels).

To change images of a single product without reseeding, use Admin → Products → Edit → Upload image.
